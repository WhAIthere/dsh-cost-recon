# =====================================================================
# DSH 看板 · 预设查看模式   ← 这个文件就是给你自己改的
# ---------------------------------------------------------------------
# 改完跑一次「刷新看板.bat」（或 python src\render_html.py）就生效。
# 看板下拉里永远还有一档「0. 上次状态（刚打开时）」，那档是程序自己的，不写在这里。
#
# 每行一档，用 | 分隔，一共 7 格：
#   名字 | 层级 | 日期 | 排序 | 花费标红(元) | 峰值标红(%) | 只标最下层(yes/no)
#
#   · 某一格留空 = 那一项不动
#   · 层级：从 day/hour/week/workspace/session/turn/model/peak/depth 里挑，最多 3 个
#           例：workspace,session,turn
#   · 日期：today = 数据最后一天 | full = 全部（最早一天 ~ 数据最后一天）| 空 = 不动
#   · 排序：ts 时间↑ / ts_desc 时间↓ / cost 花费↓ / tokens token↓ / calls 调用数↓
#           写一个 = 三层都用它（cost）；也可以分开写三个：ts_desc,ts_desc,cost
#   · 花费标红 / 峰值标红：填 0 = 关闭该项标红（峰值填 >100 也等于关闭）
#   · 只标最下层：yes = 只标当前屏幕上最深的那一层；no / 空 = 不启用
#
#  # 开头的行是注释；格子写坏了不会影响看板，只会跳过那一行并提示。
# =====================================================================
