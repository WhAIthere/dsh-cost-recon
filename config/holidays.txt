# 节假日表 —— 只管一件事：某一天算不算"高峰日"
# ---------------------------------------------------------------------------
# 每行一天：  日期 | off/work | 说明
#   off  = 法定放假         → 全天按【非高峰】算
#   work = 调休上班         → **DS 不认调休**，照普通周末算，也是【非高峰】
#                            （列出来只为对照与备查，判定结果同"普通周末"）
# 没列出的日子 = 普通日子：周一~周五按工作日的两个高峰窗口算，周末全天非高峰。
#
# 【这张表只用于对照】不参与实际开销计算 —— 实际算钱用的是官方小时桶实测出来的倍率
#   （db.apply_official_peak()，逐小时 官方金额 ÷ 官方token刊例价 => 1=谷 / 2=峰）。
#   本表用来看"实测结果和官方节假日安排对不对得上"（src/holiday_check.py）。
#
# 【有效期】2026-01-01 ~ 2026-12-31
#   数据超出这个范围时，本表不再参与判定（回落成"只看周末"的老规则），并在刷新日志里
#   提示"节假日表需要更新"。年底国务院发了下一年的通知后：把新一年的行追加进来，
#   再把上面这行的有效期改掉即可。
#
# 来源：国务院办公厅关于2026年部分节假日安排的通知
#       国办发明电〔2025〕7号（2025-11-04）
#       https://www.gov.cn/zhengce/content/202511/content_7047090.htm
# ---------------------------------------------------------------------------
